# Middlewares

This repository contains my practice and learning work on **Express.js Middleware**.

## 📌 About

In this project, I am learning how middleware works in Express.js and how it can be used to process requests and responses.

## 🛠️ Technologies Used

- Node.js
- Express.js
- JavaScript
- EJS

## 📚 Concepts Covered

- What is Middleware?
- Multiple Middleware
- Utility Middleware
- Custom Middleware
- `req`, `res`, and `next()`
- Error Handling Middleware
- Express Error Handling
- Route-level Middleware
- Using `ExpressError`
